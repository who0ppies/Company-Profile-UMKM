# Git Store — Frontend

Antarmuka website company profile UMKM Git Store, dibangun dengan Next.js (App Router, JSX) dan Tailwind CSS.

## Menjalankan

```bash
npm install
npm run dev
```

Buka http://localhost:3000. Pastikan backend berjalan di http://localhost:5000 (atau atur `NEXT_PUBLIC_API_URL`).
